# Context Knowledge Graph - ArtaLedger

Skill ini digunakan untuk mengelola dan memperbarui peta graf arsitektur proyek ArtaLedger pada berkas `docs/KNOWLEDGE_GRAPH.md`.

## 🗺️ Struktur Peta Arsitektur
- **Routes**: `routes/web.php`, `routes/api.php`
- **Controllers**: `app/Http/Controllers/`
- **Models & Migration**: `app/Models/`, `database/migrations/`
- **Services & Repositories**: `app/Services/`
- **Views**: `resources/views/`
- **Tests**: `tests/Feature/`, `tests/Unit/`
