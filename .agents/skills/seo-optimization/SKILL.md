# SEO Optimization - ArtaLedger

Skill ini mengatur praktik terbaik SEO dan penandaan Meta pada aplikasi web ArtaLedger.

## 🎯 Komponen Standar
1. **Title Tag Dynamic**: `<title>@yield('title', 'ArtaLedger - Financial & Ledger Management')</title>`
2. **Meta Description**: Ringkasan fitur manajemen keuangan dan pembukuan.
3. **Open Graph & Twitter Cards**: Metadata untuk pratinjau tautan media sosial.
4. **Structured Data (JSON-LD)**: Skema `FinancialApplication` / `SoftwareApplication`.
